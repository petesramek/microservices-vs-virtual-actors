# Security Policy

## Project scope

This repository is an educational architecture workbench and is not intended
for production deployment. It does not provide production authentication,
authorization, secret management, network security, or operational hardening.

## Supported versions

Only the latest commit on the default branch is supported. Older commits,
forks, and modified deployments are not maintained as supported releases.

## Reporting a vulnerability

Please do not report suspected security vulnerabilities through public GitHub
issues or Discussions.

Use GitHub's private vulnerability reporting feature from the repository
Security page. Include a concise description, reproduction steps, expected
impact, and any suggested mitigation.

Remove credentials, tokens, connection strings, personal data, and other
sensitive information from the report unless they are strictly necessary to
demonstrate the issue.

## Response expectations

Reports will be reviewed on a best-effort basis. Because this is a showcase
project rather than a production product, no response-time, remediation-time,
release, or long-term support commitment is provided.
